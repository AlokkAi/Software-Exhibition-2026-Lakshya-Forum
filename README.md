# 🤖 J.A.R.V.I.S — AI Personal Assistant

J.A.R.V.I.S is a Python-based AI personal assistant built using Streamlit and the Groq API.

## ✨ Features

* 💬 AI chatbot for answering questions
* 🎓 Student Mode for learning and understanding concepts
* 🎙️ Voice commands
* 🔊 Spoken AI responses
* 🌐 Website shortcuts
* 🔐 Password generation and strength checking
* 📰 News headlines

## 🛠️ Technologies Used

* Python
* Streamlit
* Groq API
* Speech recognition
* Python dotenv
* HTML and JavaScript browser speech

## ⚙️ Installation

1. Clone this repository.

2. Create and activate a Python virtual environment.

3. Install the required dependencies:

   ```bash
   python -m pip install -r requirements.txt
   ```

4. Create a `.env` file in the project folder.

5. Add your API key:

   ```text
   GROQ_API_KEY=your_groq_api_key
   ```

6. Run the application:

   ```bash
   python -m streamlit run app.py
   ```

## 🔒 Security

Never upload API keys, passwords, or other secrets to GitHub.

## 👨‍💻 Project Purpose

This project demonstrates Python programming, AI integration, voice interaction, and student-focused tools in a single application.
